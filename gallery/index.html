  • 两台均 PASS:首尾帧对齐、人物身份、表情过渡良好;无 final-frame rushing。同 seed 下两台输出高度相似,TE 量化差异(INT8 vs NVFP4)未见明显质量分歧 —— 有利于 5090 走更省显存的 NVFP4。
  • 耗时:denoise 均 ~3.0s/步 ×30;5090 全程 110s / 6000a 冷启动 210s(6000a 是 INT8 TE 27GB 首次从磁盘加载,热身后两台同级)。
  • 5090 单卡 VRAM 峰值 31.5/32.6 GB(贴顶);MultiGPU 分卡实验失败:两张消费级 5090 无 P2P,ComfyUI-MultiGPU 的 CPU 中转路径与 comfy-kitchen 张量封装不兼容(illegal memory access,服务端崩溃)—— 上游 bug,已回退单卡稳定配置。更大画布依赖 ComfyUI 动态换载(慢但可跑)。
  • BF16 oracle 已落地(上方卡片):同 seed 下 pruned INT8 与 BF16 输出高度一致,832×480 尺度肉眼未见系统性质量差 —— 按 doc Gate 3 逻辑,pruned INT8 可作为该分辨率的生产档位,BF16 保留作诊断参照。BF16 代价:3.2× denoise 耗时 + 118GB 权重。
  • 已知问题:DisTorch2 的 donor 分配未按预期落在 gpu3(DiT 溢出部分走内存流式,gpu3 闲置)—— 不影响正确性,后续想压 BF16 延迟可用 expert_mode_allocations 精调。
